### Foxhunting Description

Involves finding a transmitter signal using radio direction finding techniques, with the fox transmitting intermittently on an assigned frequency from an unknown location within Rowan County. Hunters use directional antennas, GPS, and maps to locate the signal via triangulation.

### Foxhunt Rules

Winner is typically the hunter with the least miles traveled or the first to locate the fox. Rules can be modified, such as using a point system (e.g., points for every 1/10 mile traveled and time after the fox is found). The fox can be camouflaged but not overly so, and not painted orange.

For more on Foxhunting, Amateur Radio Direction Finding, and mobile T-hunting, visit [http://www.homingin.com/](http://www.homingin.com/).
